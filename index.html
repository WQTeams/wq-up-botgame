На телефоне меню бывает спартано.
Попробуй открыть v0.app с компьютера или включить в браузере «Версию для ПК».
Через GitHub (если скачать не получается)
1. Справа вверх нажми на шестерёнку (Settings)
2. Отрой раздел Git и подпиши свой аккаунт GitHub.
3. v0 создаст репозиторий с кодом. Там можно нажать зелёную кнопку Code, а потом Download ZIP.
Скопировать файл вручную Отрой вкладу Code над превью. Слева будет список всех файлов, их можно открыть и скопировать.
Если на экране не выглядит по-другому, пришли скриншот, и я подскажу, куда нажать.
